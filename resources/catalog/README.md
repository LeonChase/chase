# Bereitgestellte Werbemotive

Diese 42 Produktvorschaubilder sind lokale Ausschnitte aus dem vom Auftraggeber für die Katalogintegration bereitgestellten CHASE-Werbekatalog (Seiten 3–13). Sie werden bewusst mit dem Projekt ausgeliefert, damit die Katalogbilder auch auf Windows/WSL ohne PDF-Zusatzprogramme sofort sichtbar sind.

Das Original-PDF, seine Dateimetadaten und die übrigen privaten Unterlagen werden nicht mitgeliefert. Ein Original-PDF kann weiterhin lokal und geschützt importiert werden. Die Vorschaubilder sind keine personalisierten Druckdateien.

Die Dateien liegen außerhalb von `public/`. Die Auslieferung erfolgt ausschließlich über die angemeldete, mandantengeprüfte Produktbildroute. Das Manifest bindet die Bilder an bekannte Quellfassungen und SHA-256-Prüfsummen. Für neue oder abweichende Katalogfassungen müssen die Motive erneut abgeglichen werden; unbekannte Quell-Hashes erhalten diese Vorschauen nicht automatisch.
